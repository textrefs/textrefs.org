# Licensing

This repository contains three kinds of work under three different licences:

| Scope                                                                       | Licence                              | File                                           |
| --------------------------------------------------------------------------- | ------------------------------------ | ---------------------------------------------- |
| **Code** — Astro/Starlight site, build scripts, config, JSON-LD shapes, API | `AGPL-3.0-or-later`                  | [`LICENSE-AGPL.md`](./LICENSE-AGPL.md)         |
| **Website content & standard text** — everything under `src/content/docs/`  | `CC BY-SA 4.0`                       | [`LICENSE-CC-BY-SA.md`](./LICENSE-CC-BY-SA.md) |
| **Registry data** — mappings, identifiers, JSON-LD records, exports         | `CC0 1.0` (public-domain dedication) | [`LICENSE-CC0.md`](./LICENSE-CC0.md)           |

The CC0 choice for registry data matches the statutes (Art. 2) — the association commits to publishing registry data "preferably under CC0 or a comparable public-benefit licence".

Contributions are accepted under the licence applicable to the file you change. See [`CONTRIBUTING.md`](./CONTRIBUTING.md) for details.
