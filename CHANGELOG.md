# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Starlight site styled per TextRefs brand (BRAND.md): Inter webfont, light/dark tokens, accent focus ring.
- Brand assets copied from `textrefs.org-upstream`: `public/logo.svg`, `public/favicon.svg`, `public/fonts/inter-v20-latin-*.woff2`.
- Site information architecture with four top-level sections: **Association**, **Standard**, **API**, **Community**, each with placeholder pages.
- Splash landing page mirroring the upstream tagline and linking to the four sections.
- `AGENTS.md` describing repository layout and conventions for contributors and agents.

### Changed

- `astro.config.mjs` rewritten: real site metadata, custom CSS, font preload, OG meta, edit links, autogenerated sidebar.
- `src/content/docs/index.mdx` replaced with the TextRefs landing page.

### Removed

- Default Starlight template scaffolding (`guides/example.md`, `reference/example.md`, `src/assets/houston.webp`).
