TextRefs is built in public by contributors who care about stable references, reusable data, and clear citation infrastructure.

This section explains how to participate, how decisions are made, and how we keep the project safe and maintainable.

## Start here

- [Contributing](/community/contributing/) explains local setup, review tracks, commit messages, and pull requests.
- [Issues and pull requests](/community/issues-and-prs/) explains which issue template to use and what maintainers need for review.
- [Governance](/community/governance/) explains how technical, expert, and Board-reserved decisions are handled.
- [Roadmap](/community/roadmap/) shows the current phase and near-term priorities.
- [Code of Conduct](/community/code-of-conduct/) applies to all project spaces.
- [Security Policy](/community/security/) explains how to report vulnerabilities privately.

## Ways to help

- Improve documentation, examples, and explanations.
- Propose or correct registry data for works, citation systems, canonical references, aliases, mappings, and resolver targets.
- Review citation-system rules with domain expertise.
- Report broken links, invalid resolver targets, or unclear specifications.
- Improve tooling, validation, schemas, and static registry pages.

For registry-data work, start with [How it works](/get-started/how-it-works/) and [Mappings and resolver targets](/get-started/mappings-and-resolver-targets/). These explain the difference between TextRefs identity, external identifiers, and URLs for reading or viewing a text.
