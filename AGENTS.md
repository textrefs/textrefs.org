# AGENTS.md

Astro + Starlight site for textrefs.org.

## Commands

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run preview` — preview build
- `npm run format` — Prettier (with `prettier-plugin-astro`)
- `npm run check` — `astro check` (TypeScript + Astro language server)
- `npm run verify` — format:check + check + build (the CI gate)
- `npm run commit` — guided conventional-commit prompt (cz-git)
- `npm run changelog` — regenerate `CHANGELOG.md` from git history (git-cliff)

Hooks install automatically on `npm install` (husky): Prettier runs on staged files, and `commitlint` rejects non-conventional commit messages.

## Layout

- `src/content/docs/{association,standard,api,community}/` — site sections (autogenerated sidebar)
- `src/content/docs/index.mdx` — landing splash
- `src/styles/brand.css` — brand tokens (see `../textrefs.org-upstream/BRAND.md`)
- `public/{logo.svg,favicon.svg,fonts/}` — brand assets, copied from upstream

## Conventions

- Brand tokens (`#111`/`#F0F0F0`/`#0A58CA`/`#6EA8FE`) are authoritative — do not introduce new colours.
- Self-hosted Inter only; no external font requests.
- Every page needs `title` and `description` frontmatter.
- WCAG 2.2 AA is the baseline; AAA for primary text pairs.
