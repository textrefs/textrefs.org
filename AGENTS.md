# AGENTS.md

Astro + Starlight site for textrefs.org. See [`README.md`](./README.md) for the project overview.

## Commands

- `npm run dev` — local dev server
- `npm run build` — production build
- `npm run format` — Prettier (with `prettier-plugin-astro`)
- `npm run check` — `astro check`
- `npm run verify` — format:check + check + build (the CI gate)

Husky installs on `npm install`: Prettier runs on staged files, `commitlint` enforces Conventional Commits.

## Layout

- `src/content/docs/{association,standard,api,community,get-started}/` — site sections (autogenerated sidebar)
- `src/content/docs/de/` — German mirror (see Localization)
- `src/styles/brand.css` — brand tokens
- `public/{logo.svg,favicon.svg,fonts/}` — brand assets
- `standard/`, `data/`, `api/` — scaffolds for the future repo split

## Conventions

- Brand tokens (`#111` / `#F0F0F0` / `#0A58CA` / `#6EA8FE`) are authoritative — do not introduce new colours.
- Self-hosted Inter only; no external font requests.
- Every page needs `title` and `description` frontmatter.
- WCAG 2.2 AA baseline; AAA for primary text pairs.

## Localization

- English at the root URL (e.g. `/association/statutes/`); German under `/de/`.
- Only legally relevant Association pages are bilingual today.
- For statutes, governance, expenses, and mission: the German text is legally binding; the English version is a non-binding translation and must carry a `:::caution[Non-binding translation]` aside at the top.
- To add a German translation: mirror the file under `src/content/docs/de/...` with the same filename and frontmatter.

## Mirrored community files

`CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, and `SECURITY.md` live at the repo root (for GitHub's Community profile) and are mirrored at `src/content/docs/community/` with Starlight frontmatter. Edit both in the same commit.
